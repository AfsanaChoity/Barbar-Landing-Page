# Barber's Time — Landing Page

**Live Demo:** [barberstime.netlify.app](https://barberstime.netlify.app/)

A clean, responsive landing page for **Barber's Time**, built with React, Ant Design and Tailwind CSS.  
This project focuses on smooth entrance animations, mobile-first design, and an easy-to-edit structure.

---

## 🚀 Features
- Responsive design (mobile-first)
- Animated hero section with phone/device effects
- Scroll-triggered animations using IntersectionObserver
- Map view with location pins
- Easy customization of content, assets, and styles

---

## 🛠️ Tech Stack
- [React](https://reactjs.org/)  
- [Tailwind CSS](https://tailwindcss.com/)  
- Netlify (for deployment)
